\chapter{Conclusion and Future Work}
\label{Conclusion_and_Future_Work}

\section{Summary of Achievements}

This project successfully established a comprehensive, low-cost framework for high-precision Indoor Positioning by conducting a rigorous evolutionary study of tracking technologies. The work transitioned from a foundational Wi-Fi (RSSI) and Machine Learning dependency into a highly optimized 24GHz mmWave radar architecture, proving that sophisticated Edge Processing can overcome the most critical flaws of wireless localization. 

The primary achievements of this project include:

\subsection{The Initial RSSI and Machine Learning Baseline}
The project successfully established an initial theoretical baseline utilizing ESP-NOW RSSI metrics and an MLPRegressor Machine Learning model. By exploring deep learning networks consisting of hidden layers and normalized data arrays, the work demonstrated the baseline feasibility of mapping volatile Wi-Fi signal attenuation to geometric distances \cite{xiao2016indoor}. This intensive initial phase provided the critical mathematical proof that while RSSI is heavily prone to multipath fading, computational algorithms can extract theoretical positioning data \cite{zhang2019deep}. Identifying these limits directly motivated the project's pivot to superior hardware.

\subsection{The Evolutionary Pivot to mmWave Radar}
Building directly upon the lessons learned from the RSSI limitations, the project successfully executed a hardware pivot to the LD2450 mmWave sensor. By transitioning from signal attenuation to Frequency Modulated Continuous Wave (FMCW) physics, the project geometrically solved the instability issues inherent to ambient Wi-Fi tracking. The work successfully engineered the ESP32 microcontroller to parse the high-speed 256,000 bps UART hexadecimal stream from the radar's internal DSP, resulting in real-time Cartesian (X, Y) coordinate generation without the massive latency bottlenecks that plagued the earlier Machine Learning models.

\subsection{Phased Architecture Implementation}
The project introduced and proved a three-phase architectural evolution. Phase 1 (Single Node Validation) successfully established a flawless software parsing logic that ingested UART data and applied digital bounds to filter environmental "ghost" anomalies. Phase 2 (Multi-Node Coverage) conquered the mmWave "line-of-sight" vulnerability by deploying overlapping sensor nodes. Finally, Phase 3 aggregated these wireless nodes using ESP-NOW to funnel coordinate data into a central tracking dashboard.

\subsection{Low-Cost Reproducible Approach}
Despite pivoting to advanced radar technology, the entire system remained rigorously tethered to commercial affordability. By utilizing ESP32 development boards paired with low-cost LD2450 modules, the system guarantees high-fidelity positioning for under a fraction of the cost of traditional optical or Ultra-Wideband (UWB) commercial setups. This reproducibility ensures that the system can be easily replicated, scaled, and deployed by researchers without extreme infrastructure budgets.

\section{Key Takeaways: A Comparative Analysis}

The evolutionary development of this Indoor Positioning System revealed critical comparative principles between ambient signal tracking and direct wave reflection:

\subsection{Wi-Fi Propagation vs. FMCW Radar Physics}
The most profound takeaway is the fundamental disparity in environmental robustness. Accurate RSSI localization depends entirely on static calibration \cite{rappaport1996wireless}; if a room's physical layout changes (e.g., a door opens, or furniture is moved), the specific path-loss variables ($A$ and $n$) instantly become obsolete due to shifting multipath fading \cite{goldoni2010experimental}. In stark contrast, FMCW mmWave radar proved entirely immune to these ambient shifts. Because radar tracks objects through direct wave reflection rather than signal degradation, it operates identically in an empty room, a cluttered office, and perfectly dark environments.

\subsection{Machine Learning vs. Hardware Edge Processing}
The project highlighted a critical computing bottleneck regarding microcontrollers. The initial intent to use an MLPRegressor demonstrated that "fixing" corrupted RSSI signals via Machine Learning requires substantial computational overhead and heavy datasets \cite{he2016wifi}. Alternatively, the LD2450 outsources this heavy mathematics entirely to its onboard Digital Signal Processor (DSP). By shifting the workflow from *algorithmic prediction* to *hardware edge-processing*, the ESP32 was freed to focus strictly on real-time networking, dramatically lowering system latency.

\subsection{Data-Level Deduplication over RF Collision}
In the earlier RSSI stages, operating multiple tracking targets simultaneously triggered catastrophic wireless packet collisions in the 2.4 GHz spectrum \cite{lemic2017experimental}. The mmWave pivot solved this, but introduced a new "Data Collision" problem: if two sensors see the same human, the system records duplicate targets. Resolving this via Euclidean distance thresholding—mathematically merging two close coordinate dots into one master target—proved that advanced positioning networks require data-level sensor fusion logic rather than mere radio frequency time-slotting.

\section{Future Work}

The evolutionary architecture designed in this thesis opens Several promising directions for extending the positioning ecosystem:

\subsection{Hybrid Sensor Fusion (UWB + mmWave)}
Having completely established the limitations of RSSI modeling in earlier phases, the definitive future iteration of this system is to combine the current mmWave architecture with Ultra-Wideband (UWB) technology. This creates a highly advanced "Macro-Micro" tracking ecosystem. While UWB provides pristine, absolute localization across massive warehouse distances, it remains prohibitively expensive for dense deployment. The hybrid solution proposes using sparse UWB anchors to identify the macro-scale zone of a target, while utilizing clusters of the affordable LD2450 mmWave sensors inside individual rooms to provide localized, high-resolution geometry \cite{bahl2000radar}.

\subsection{Predictive Machine Learning Trajectories}
While Machine Learning was deemed too heavy for cleaning degraded RSSI data, it holds immense potential for the pristine coordinate data generated by the mmWave. Future work could apply Recurrent Neural Networks (RNNs) or Kalman Filtering directly to the radar's XYZ tracking arrays \cite{hoang2019recurrent}. Instead of guessing where someone *is*, the AI could mathematically predict where the target *is about to walk next*, dynamically smoothing the visual trajectory line on the dashboard.

\subsection{Environmental Deep Sleep and Power Optimization}
For battery-powered deployments, future work should deeply integrate the ESP32's power states with the LD2450's hardware triggers. The radar draws roughly 50mA of current, making prolonged battery operation challenging. A potential upgrade involves utilizing a secondary passive infrared (PIR) sensor to keep the radar completely disabled until human body heat is detected, extending battery operation from mere hours to multiple weeks.

\subsection{Integration with Existing Smart-Building Infrastructure}
The ESP32 platform natively speaks Wi-Fi and Bluetooth. Future implementations could integrate this mmWave positioning matrix directly into Home Assistant or corporate MQTT brokers. This would allow the high-precision human tracking to dynamically trigger HVAC systems, control automated lighting specific to different quadrants of a room, or enforce secure localized access policies \cite{jimenez2018indoor}.

\subsection{Three-Dimensional (3D) Spatial Expansion}
The current testbed restricts analysis to a two-dimensional Cartesian plane (X and Y limits). Future research could upgrade the hardware tier to advanced 3-dimensional radar modules (e.g., LD2460 or Texas Instruments equivalents) that yield Z-axis elevation. Doing so would enable the detection of complex human posturing, differentiating between an individual who is standing, walking, or has suffered a critical fall \cite{yassin2017recent}.

\section{Concluding Remarks}

This project serves as a highly robust comparative evaluation of indoor positioning paradigms. It successfully demonstrates the theoretical limitations of using uncalibrated ambient Wi-Fi (RSSI) for proximity sensing, formally concluding that it is insufficient for precise localization. By executing an engineered shift to mmWave FMCW architectures, the resulting system perfectly balances the affordability of ESP32 microcontrollers with the pristine accuracy of commercial radar. Ultimately, this multiphased approach—scaling from isolated boundary testing to multi-node spatial deduplication—has produced a scalable baseline framework, paving the way for the ultimate future implementation: a synergistic hybrid model combining the long-range absolute positioning of UWB with the cost-effective, high-resolution local tracking of mmWave arrays.
